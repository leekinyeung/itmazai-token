# Using the console

The site administrator controls which console sections are available. The features you see may vary with your account permissions and site settings.

## Model Square

Find a model and check its full model ID, supported capabilities, and displayed pricing. Chat, image generation, and other tasks require the appropriate endpoints and client capabilities.

## API Keys

Create and manage access keys for your applications. If a connection fails, check the key's status, expiration date, available quota, and model or access restrictions. Using a separate key for each application makes it easier to disable access and troubleshoot issues.

## Wallet

View your account balance and the ways your site offers to obtain quota. If your site provides plans, also check that your plan is active. Available options depend on what your site displays.

## Usage Logs

Find request records and check the model, time, result, and cost. When reporting a problem, include the time, model name, error message, and any request ID shown on the page. Remove API keys and private conversation content before sharing.
