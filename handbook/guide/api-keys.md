# API 密钥管理

[API 密钥](https://taodock.com/keys)是应用访问 TaoDock 的凭据。登录密码用于进入控制台；API 密钥用于客户端和程序，两者不能混用。

## 创建与命名 {#create}

1. 登录后打开 [API 密钥页面](https://taodock.com/keys)。
2. 点击「创建 API 密钥」，填写能辨认用途的名称，例如 `Cherry Studio` 或 `个人脚本`。
3. 选择账号可用的分组，并按需要设置额度、有效期和访问限制。
4. 保存后，在列表中复制密钥，填写到应用的 API Key 字段。

为不同应用单独建密钥，可在排查请求记录或停用某个应用时减少互相影响。

## 额度、有效期和访问限制 {#restrictions}

| 设置 | 含义与使用建议 |
| --- | --- |
| 分组 | 决定该密钥使用的模型服务范围；先从页面提供的选项中选择 |
| 密钥额度 | 限制该密钥能够消耗的额度，不会给账户增加余额 |
| 不限制额度 | 取消这把密钥自身的额度上限，仍受账户余额及其他账户规则限制 |
| 有效期 | 到期后该密钥不能继续请求；为临时应用设置合适的到期时间 |
| 模型限制 | 只允许该密钥调用所选模型，新增客户端模型时检查这里是否也允许 |
| IP 限制 | 限制请求来源 IP；用于有固定出口的应用，不确定出口时先留空 |

手机网络、家庭网络和代理的出口 IP 可能变化。开启 IP 限制后突然无法调用，应核对实际请求出口，而不是反复创建新密钥。

## 复制地址与接入应用 {#connect}

页面右上角的「API 地址」提供 TaoDock 当前入口：`https://taodock.com`。是否在客户端的地址框中附加 `/v1`，取决于它会自动追加的路径，具体见[客户端配置速查](./clients.md#settings)。

密钥行的操作菜单提供复制、编辑及客户端接入操作。「聊天」子菜单可选择当前配置的客户端；安装对应客户端后使用，详细步骤见[客户端接入](./clients.md#import)。

## 停用、删除与密钥泄露 {#revoke}

不再使用某个应用时，在密钥列表中停用该密钥。重新接入时，先确认密钥处于启用状态且未过期。

如果密钥曾被放到公开仓库、分享链接或不可信位置，先停用旧密钥，再创建新密钥并更新应用配置。删除前确认所有依赖该密钥的应用都已完成更换。

分享错误信息时移除完整密钥。网页前端、公开配置文件和截图中都不应包含可用密钥。
