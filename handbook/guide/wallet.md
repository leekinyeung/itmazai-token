# 钱包与用量

打开 [TaoDock 钱包](https://taodock.com/wallet)查看余额和账户提供的额度获取方式。TaoDock 当前以 **USD** 展示额度与相关金额。

## 使用前检查两项额度 {#quota}

1. **账户余额 / 可用套餐额度**：在钱包中查看。
2. **API 密钥额度**：在 [API 密钥](https://taodock.com/keys)中查看当前密钥的设置和剩余额度。

账户有余额，但密钥额度已经用完，仍然可能无法请求；勾选密钥的「不限制额度」也不代表账户可以无限使用。

## 获取额度 {#funds}

在钱包中使用当前页面提供的充值、兑换或套餐入口。提交前核对页面显示的支付金额、可得额度和使用条件。

- 使用兑换码时，在钱包的兑换入口输入并提交，成功后检查余额变化。
- 使用在线支付时，先核对订单信息，再按页面提示完成支付；已支付未到账时先检查订单状态，不要为同一笔问题连续重复付款。
- 使用套餐时，确认有效期、可用模型与分组，以及额度的使用规则。套餐是否可购以钱包实际展示为准。

充值金额、支付渠道和模型单价请查看当前页面，核对有效报价和使用条件后再提交。

## 查询本次费用 {#usage}

打开[模型广场](https://taodock.com/pricing)查看调用前的价格信息；调用后在[普通日志](https://taodock.com/usage-logs/common)或[任务日志](https://taodock.com/usage-logs/task)核对实际使用记录。

费用可能随所选模型、分组、输入与输出用量以及计费方式变化。按 Token 计价的对话和按图片或任务计价的服务，不能只比较请求次数。

## 遇到扣费或到账问题 {#questions}

准备发生时间、订单号或请求标识、模型名称、金额和错误说明，再通过 TaoDock 页面提供的支持渠道反馈。不要提供登录密码、邮箱验证码或完整 API 密钥。

不要仅凭客户端报错推断请求一定没有执行；先核对 TaoDock 日志中的记录与状态，再决定是否重新提交。
