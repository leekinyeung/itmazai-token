# 控制台使用

控制台中的可用入口由站点管理员配置；你看到的功能可能因账号权限和站点设置而不同。

## 模型广场

查找要使用的模型，确认其完整模型 ID、支持的能力和页面展示的价格信息。对话、图片和其他任务需要使用相应的接口与客户端能力。

## API 密钥

为应用创建和管理访问密钥。接入失败时，检查密钥状态、有效期、可用额度以及模型或访问限制。建议为不同应用分别创建密钥，便于停用和排查。

## 钱包

查看账户余额与站点提供的额度获取方式。如果你的站点提供套餐，也需要确认套餐是否处于有效期内。实际可用方式以页面为准。

## 使用日志

查找请求记录，核对模型、调用时间、结果和费用。反馈问题时提供发生时间、模型名称、错误信息以及页面显示的请求标识；请移除 API 密钥和对话中的私人内容。
