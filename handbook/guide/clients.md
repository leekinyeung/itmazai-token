# 连接 AI 客户端

本页适用于支持自定义 OpenAI 兼容接口的客户端。不同客户端的字段名称和地址拼接方式可能不同，请结合该客户端的设置说明填写。

## 准备三个配置值

| 配置项 | 填写内容 |
| --- | --- |
| API 地址 / Base URL | 通常为 `https://你的站点域名/v1`，以客户端要求为准 |
| API Key | 在 Taodock「API 密钥」页面创建的密钥 |
| 模型名称 | 从模型广场复制的完整模型 ID |

如果客户端提供「OpenAI 兼容」或「自定义服务商」，选择这一类型后填写上述信息。某些客户端会自动补充 `/v1`，此时应填写站点根地址，避免出现 `/v1/v1`。

## 测试连接

保存配置后，选择已配置的模型并发送一条简短消息。收到回复后，可以在 Taodock「使用日志」中核对记录。

## 连接失败时

1. 确认填写的是服务站点域名；文档站域名不提供模型接口。
2. 检查地址是否重复拼接 `/v1` 或 `/chat/completions`。
3. 检查密钥是否有效、账号是否有可用额度，以及模型名称是否准确。
4. 使用[快速开始](../quick-start.md)中的 cURL 示例对照验证，并保留具体错误信息。

更多排查方法见[常见问题](../faq.md)。
