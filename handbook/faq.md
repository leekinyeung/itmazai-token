# 常见问题

## 不知道应该填写哪个 API 地址

API 地址来自你使用的服务站点，不是文档站。通常需要填写站点地址或以 `/v1` 结尾的 Base URL，具体取决于客户端是否会自动拼接路径。参照[地址说明](./api/overview.md)。

## 提示密钥无效或没有权限

检查密钥是否复制完整、是否已停用或过期，以及是否设置了模型或访问限制。直接发起 HTTP 请求时，确认请求头使用 `Authorization: Bearer YOUR_API_KEY`。

## 提示模型不存在或模型不可用

从模型广场重新复制完整模型 ID，检查账号及密钥能否使用该模型。若名称与权限均正确，请联系管理员检查当前模型服务状态。

## 提示额度不足

查看钱包中的可用余额、套餐状态以及当前密钥的额度限制。具体限制以错误响应和站点页面显示为准。

## 提示限流或请求过多

降低应用的并发请求数，按照接口返回的说明稍后重试。重试仍受限时，将发生时间和错误信息提供给管理员。

## 请求超时或无法连接

先检查域名、网络连接和客户端代理设置，再用相同模型进行一次简单请求。若问题持续，提供发生时间、模型名称和错误信息，便于管理员排查。

## 如何反馈问题

提供以下信息：发生时间、使用的客户端及版本、模型名称、复现步骤、HTTP 状态码和完整错误说明。如页面显示请求标识，也请一并提供。分享前移除 API 密钥、个人信息及对话中的私人内容。
