二、我们如何使用信息

我们仅为已告知的目的及与之直接相关、依法允许的用途处理信息，主要包括：

  • 提供服务：创建和管理账户、验证 API 请求、转发模型调用、交付结果及管理任务。
  • 处理交易：完成充值或订阅、核对订单、计算用量及费用、处理售后和交易争议。
  • 保障安全：识别异常访问、欺诈和滥用，排查故障，维护服务稳定及开展必要审计。
  • 沟通与支持：发送验证码、安全提醒、交易或服务通知，回应您的请求。
  • 履行义务：遵守适用的记录保存要求，依法处理投诉、争议和有权机关的有效要求。

依法需要同意的处理，我们会取得您的同意；为履行合同或法定义务等依法允许的必要处理，按相应依据开展。将信息用于与原目的不相关的新用途时，我们会事先说明，并依法取得所需同意。接受本政策不等于同意接收营销信息或接受非必要追踪。

三、Cookie 与本地存储

我们使用 Cookie、浏览器本地存储及类似机制维持登录会话、完成必要安全验证，并保存语言、主题和界面偏好。在线模型体验还会在当前浏览器中保存部分对话和参数，以恢复使用状态。

本地对话保存在您的设备和浏览器环境中；发起模型调用时，相关上下文仍会发送至平台及对应服务商。您可以使用页面提供的清理功能或浏览器设置删除网站数据、限制 Cookie；这可能使您退出登录或丢失本地记录。清除网站数据不会同步删除服务器日志、任务记录或第三方副本。

如另行启用非必要统计、广告或追踪技术，我们会说明用途、提供方和管理方式，并依法取得所需同意。

四、AI 请求、结果与日志

4.1 请求如何处理

平台接收请求后，会根据您选择的模型、接口和路由配置，进行必要的格式转换，并将完成请求所需的输入、上下文、文件和参数发送至相应模型或渠道服务商。您提交的外部链接可能由平台或服务商读取；请勿提交不应被访问的私有资源或含有凭据的链接。

4.2 内容与调用记录的区别

调用日志主要记录模型、时间、用量、费用、状态和错误等信息，不等同于完整对话历史。请求处理可能使用内存或临时文件；异步任务可能保存任务数据、生成结果或结果链接。错误信息、诊断日志和您提交的客服材料也可能包含输入或输出片段，因此不能将普通 API 转发理解为所有处理环节均无内容留存。

您可以在账户安全设置中管理调用及错误日志的“记录 IP 地址”选项。关闭该选项仅影响相应日志的后续 IP 记录，不会自动删除历史记录，也不影响登录会话、安全审计或网络访问等必要处理。

4.3 训练与人工访问

我们处理输入和输出是为了完成您请求的服务。若拟另行将这些内容用于模型训练、广告或其他独立用途，我们会事先说明目的与范围，并依法取得所需同意。排障、处理投诉或安全事件所需的人工访问，应限于获授权人员和必要范围。

外部模型或渠道服务商可能适用独立的留存、安全监测和模型改进规则。请在提交敏感或保密内容前了解相应条件；本政策不对所有服务商作统一的零留存或不训练承诺。如需特定处理条件，请先通过本政策的联系邮箱咨询。

五、信息共享与第三方服务

我们不出售您的个人信息。为提供您使用的功能，我们可能在必要范围内向以下类别的服务商提供信息：

  • 模型或渠道服务商：处理模型调用所需的请求内容、文件、参数及技术信息。
  • 托管与数据服务商：支持平台运行、存储、网络、安全和备份所需的数据。
  • 支付服务商：完成交易所需的订单、金额、支付状态及必要账户关联信息；您在支付页面填写的付款资料还受相应支付服务商规则约束。
  • 身份、安全及邮件服务商：在相关功能启用时，处理登录授权、安全验证或消息投递所需的信息。

我们会根据处理关系，通过适当的合同或其他措施约束受托方的用途、访问和保存，要求其保护个人信息。第三方独立决定处理目的或方式时，其处理还适用自身隐私政策；我们仍对自身的信息提供行为承担适用法律要求的责任。依法需要具体接收方告知、单独同意或其他程序的，会在相关处理前完成。

法律要求、有权机关的有效要求，或依法保护用户及他人权益所必需时，我们可能披露必要信息。如因合并、重组或业务转移需要转移个人信息，我们会依法告知接收方及其责任；改变用途时，另行履行所需程序。

六、存储地区与跨境处理

Taodock 的运营主体为香港码载科技，平台业务数据主要存储于中国香港。浏览器本地数据保存在您使用的设备和浏览器中。

主要存储地区不代表所有处理环节均发生在香港。您选择的模型或渠道服务商，以及相关技术服务商，可能在其他国家或地区处理请求、文件、任务结果或必要技术数据；具体范围取决于使用的服务及相应安排。

我们会按适用法律处理跨境传输，包括在依法需要时说明接收方、处理目的、信息类别和权利申请方式，并完成必要的同意、评估、合同或其他保护程序。从中国内地向香港或其他境外地区提供个人信息时，如适用内地的数据出境规定，还须满足相应要求。选择模型或提交请求不替代法律要求的专门告知或单独同意。

七、信息保存与删除

我们按提供服务及履行适用义务所需的最短期限保存个人信息。不同资料具有不同的处理目的和保存条件：

  • 账户资料：用于账户存续和相关服务；注销后，仅保留依法必要或处理未结事项所需的部分。
  • 请求、任务与诊断资料：按完成处理、提供结果、排查问题及必要保全的需要保存；临时请求处理不等于建立永久对话档案。
  • 调用、安全及交易记录：按使用查询、对账、安全审计、争议处理及法律规定所需期限保存。
  • 客服与沟通资料：在处理事项及必要的后续跟进期间保存。
  • 浏览器本地资料：保留至您清理、功能移除或浏览器及设备机制清除。

当信息不再必要且无需依法保留时，我们会删除或匿名化。因法定义务、未结争议或技术限制暂时不能删除的，将限制其用途并继续保护；备份中的副本按相应备份管理流程处理。账户注销不等于所有数据库、日志、备份及第三方副本即时物理删除，页面可查询的时间范围也不等于自动删除期限。

如需了解某类资料的具体保存安排或提出删除申请，请联系 support@taodock.com，我们会根据资料类别、实际处理情况及适用要求答复。

八、我们如何保护信息

我们根据数据类别和风险采取合理的技术与管理措施，包括传输保护、身份验证、访问权限控制、凭据保护及必要审计。账户密码以不可逆散列进行校验，不以明文作为密码校验记录；API 令牌和其他需要用于验证或连接外部服务的凭据，按其用途采取访问限制和保护措施。

请妥善保管密码、API 密钥、验证码及恢复码，按需启用多因素认证或通行密钥。向客服提交截图、日志或请求示例前，请遮盖可用凭据及与问题无关的个人信息。我们不会要求您通过邮件提供密码、完整 API 密钥或恢复码。

任何系统都无法保证绝对安全。如发生个人信息泄露、篡改或丢失等事件，我们会采取补救措施，并按适用要求报告或通知受影响人士，说明可能影响和可采取的保护措施。

九、您的权利与选择

您可以通过账户页面管理资料、凭据、会话及相关偏好，并在适用法律规定的范围内提出以下请求：

  • 查阅与复制：了解我们是否持有您的个人信息，并申请查看或取得副本。
  • 更正与补充：更新不准确或不完整的账户资料，或请求我们更正其他相关记录。
  • 删除与注销：使用账户安全页面的“删除账户”功能，或申请删除不再必要或依法应删除的信息。注销前请保存所需资料并妥善处理未完成交易。
  • 撤回同意与管理偏好：关闭可选功能、解除绑定，或联系我们撤回以同意为依据的处理。撤回不影响此前依法开展的处理或其他合法必要处理。
  • 限制、反对、转移与解释：在相应法律赋予这些权利且满足条件时，提出限制处理、反对处理、资料转移或解释说明的申请。
  • 投诉：通过下述邮箱反映问题，或依法向香港个人资料私隐专员公署等有管辖权的监管机构投诉。

请向 support@taodock.com 发送申请，说明账户关联信息、请求类型和范围。我们可能要求与风险相称的必要身份核验，以保护您及他人的信息；不会要求提供可直接使用的认证凭据。

我们会在适用法定期限内处理并答复。香港《个人资料（私隐）条例》下的查阅资料要求，一般须于收到要求后 40 个历日内依从或依法作出答复；如依法不能完全依从，会说明原因及后续安排。其他权利和期限依相应法律适用；本政策不限制您依法享有的权利。

十、未成年人保护

本服务面向年满 18 周岁且具有相应民事行为能力的用户，不面向未成年人主动提供服务或收集其个人信息。如果您是监护人，并认为未成年人未经适当授权向我们提供了信息，请联系我们。我们会核实情况，并依法删除、限制处理或采取其他必要保护措施。

十一、您提交的他人信息

如果您通过 Taodock 处理客户、员工、应用用户或其他人的个人信息，请确认具备合法依据，并已履行必要的告知、授权和保护义务。请特别留意敏感个人信息、未成年人信息及跨境传输。

您向自己的用户提供应用服务时，应提供反映实际数据流向的隐私说明。我们受您委托处理数据时，双方的范围、指令和责任应由适用的数据处理约定明确；我们为账户管理、安全或法定义务独立处理的信息，仍由我们承担相应责任。

十二、政策更新

我们可能因服务、处理方式或法律要求变化更新本政策，并标注更新日期。本版于官网正式发布后适用；后续重大变更会通过网站公告、页面提示或必要邮件等适当方式告知，并说明适用时间。

依法需要重新取得同意的，我们会在开展相关处理前完成；不会仅以您继续使用服务推定已经取得法律要求的特定同意。您可以保存或打印本政策。
