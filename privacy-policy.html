二、处理目的与合法性依据

我们根据具体处理活动适用相应合法性依据，包括为订立、履行您作为一方当事人的合同所必需，履行法定职责或法定义务，以及在依法需要时取得您的同意。我们不会将同一项依据无差别适用于所有处理活动。

  • 提供服务：管理账户、验证请求、转发模型调用、交付结果、维护订单及服务权益。
  • 安全与合规：识别异常访问、排查故障、处理滥用与投诉、履行网络安全及依法适用的记录保存义务。
  • 沟通与支持：发送验证码、服务变更、安全提醒、交易通知，并回应您的咨询。
  • 可选功能：根据您的选择处理第三方绑定、邀请活动、偏好保存等功能涉及的信息。

如需将信息用于与原目的不相容的新用途，我们会事先说明，并在依法需要时重新取得同意。营销推送、非必要追踪等活动不以接受本政策作为一揽子授权。

三、Cookie 与本地存储

我们使用 Cookie、浏览器本地存储或其他必要的客户端存储机制维持登录状态、进行安全验证，以及保存语言、主题、通知和界面偏好。在线模型体验功能会将部分对话内容和参数配置保存在您当前浏览器的本地存储中，以便恢复使用状态。

本地存储中的对话保存在您使用的设备和浏览器环境内；您实际发起模型调用时，相关对话上下文仍会作为请求发送至平台和对应外部。清除本地对话或网站数据，不会自动删除平台日志、任务记录或第三方留存的副本。

您可以通过浏览器设置清除网站数据或限制 Cookie。清除或限制必要存储可能导致退出登录、偏好丢失或部分功能无法正常工作。使用公共或共享设备后，请退出账户并按需清除网站数据。若另行启用非必要统计、广告或追踪技术，我们会说明其用途、提供方与关闭方式，并在依法需要时先取得同意。

四、AI 请求、生成结果与日志

4.1 请求转发与任务处理

为完成您选择的 AI 服务，平台会读取并处理请求内容，根据模型和路由配置进行必要的格式转换，再向对应外部发送与完成该请求有关的内容和参数。异步任务可能保存任务标识、状态、必要的任务数据，以及生成结果或结果链接。输入中的文件及外部链接还可能由平台或外部按接口要求读取。

4.2 调用日志与内容留存

平台可以记录账户关联信息、模型、调用时间、用量、费用、耗时、状态、请求标识和错误信息等调用日志。完整输入或输出的持久化留存应以实际内容记录策略为准；部分任务记录、错误信息、调试日志或客服排障材料也可能包含您提交的内容片段。

建议内容处理规则：普通 API 输入、输出用于完成请求，不作为永久对话档案保存。请求体可能暂存在内存或磁盘缓冲中，并通过正常请求清理释放；任务数据、结果引用及错误或诊断片段可能另行保存。建议在任务完成或问题处理结束后 30 个自然日内清理这些资料，依法需要保全的部分除外。该规则仍需与线上版本及日志配置核对，不代表现有系统已落实所有期限。外部保存规则另行适用，可能更长。

您可以在账户安全设置中管理调用及错误日志的“记录 IP 地址”选项。该选项仅控制相应日志中的 IP 记录，不影响为登录会话、安全审计、网络访问或法律义务所必需的其他 IP 信息处理；关闭该选项也不会自动删除已有记录。

4.3 训练、人工访问与第三方规则

我们为提供您请求的服务处理输入和输出。如拟将这些内容另行用于模型训练、广告或其他独立用途，我们会事先说明具体目的、范围和规则，并在依法需要时另行取得同意。工作人员处理排障或安全事件时，仅应在必要范围及相应权限内访问信息。

具体处理活动可能适用不同的保存、安全监测或模型改进规则，取决于功能和相应安排。本政策不承诺所有处理路径均为“零留存”或一律“不用于训练”；影响用户权益的具体处理条件，应在相应活动发生前说明，并依法另行取得必要同意。

在提供依法需要专门告知、同意、评估或数据出境程序的服务前，应先完成相应要求，包括接收方信息、处理目的和方式、信息种类及权利申请方式。选择模型、提交请求或接受本政策不替代依法需要的单独同意程序。

八、信息安全与事件处理

我们将根据所处理信息的种类、目的和风险，采取必要的技术与管理措施，包括访问权限控制、身份验证、必要的传输保护、凭据保护、操作审计，以及与实际部署相适应的备份和安全管理措施。密码应以不可逆密码散列进行校验和存储；API 令牌、外部密钥及其他需用于请求验证或转发的凭据，按其用途采取访问限制和保护措施。

请妥善保管账户、令牌和验证资料，按需启用多因素认证或通行密钥，并在发现泄露风险时及时修改密码、撤销令牌或终止异常会话。向客服提交材料时，请先遮盖密码、验证码、恢复码、完整密钥和与问题无关的个人信息。

如发生或可能发生个人信息泄露、篡改、丢失等安全事件，我们会采取补救措施，并按适用法律要求报告及通知相关个人，说明涉及信息、可能影响、已采取措施及您可采取的保护方式。

九、您的权利与申请方式

在适用法律规定的范围内，您可以行使以下权利：

  • 查阅与复制：通过账户资料、令牌、会话及日志等页面查看相关信息；日志导出功能开放时，可导出自己的调用日志。页面未提供的信息可按第十三条说明的途径申请。
  • 更正与补充：在相关设置中修改可编辑资料，或联系更正不准确、不完整的信息。
  • 删除：在处理目的已实现、保存期限届满、撤回同意或其他法定情形下申请删除。清除浏览器本地记录、平台数据和外部副本属于不同处理范围。
  • 撤回同意与限制处理：通过关闭可选功能、解除绑定或联系我们撤回相应同意或申请限制处理。撤回不影响此前已依法开展的处理，也不影响其他具备合法依据的必要处理。
  • 注销账户：通过账户安全页面的“删除账户”功能或联系我们申请。注销前可按需导出资料、处理未完成交易并保存必要凭证；注销不免除我们依法应履行的保留和保护义务。
  • 转移与解释说明：在符合适用法律规定条件时，申请个人信息转移，或要求我们解释本政策及相关处理规则。

请使用 TaoDock 实际公布或向您提供的服务沟通渠道说明账户关联信息和申请事项；当前申请渠道状态见第十三条。我们可能进行与风险相适应的身份核验，仅收集核验所必需的信息，且不会要求您提供账户密码、完整 API 密钥或恢复码。

建议响应目标：收到申请后 3 个工作日内确认收悉，在完成必要身份核验后 15 个工作日内给出实质答复；法定期限更短的优先适用，依法可延期的应说明理由。该承诺以建立有效申请渠道为前提。不能满足申请的，应说明理由及后续途径；法定投诉与争议解决权利不受影响。

十、未成年人个人信息

用户协议拟采用仅限年满 18 周岁且具有相应民事行为能力人士使用的规则，本稿不拟向未成年人提供服务。未来如另行提供，应先评估并落实相应个人信息保护要求。

不满十四周岁未成年人的个人信息属于敏感个人信息。若拟向其提供服务并处理相关信息，我们会依法取得监护人同意并制定专门规则；在具备相应条件前，不应主动收集此类信息。若您是监护人并认为我们未经适当授权处理了相关信息，请通过第十三条联系我们，我们会核实并依法处理。
